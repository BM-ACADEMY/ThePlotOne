# ThePlotOne

A real estate portal and property management platform.

## Structure
- `client/` - Frontend application (React / Vite)
- `server/` - Backend API (Node.js / Express / MongoDB)

## Setup & Run

### 1. Server
```bash
cd server
npm install
npm run dev
```

### 2. Client
```bash
cd client
npm install
npm run dev
```
